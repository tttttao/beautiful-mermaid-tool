## 2024-05-24 - Accessible clipboard feedback in interactive code editors
**Learning:** When adding "Copy" buttons to complex interactive components like code editors, dynamically swapping `title` or `aria-label` text (e.g. from "Copy" to "Copied") or solely relying on color/icon changes fails to provide immediate and reliable feedback to screen readers. Screen readers often don't announce standard attribute changes immediately unless explicitly instructed or unless focus is lost and regained.
**Action:** Use a dedicated visually hidden `aria-live="polite"` region strictly for screen reader announcements alongside the visual state changes. This ensures accessible feedback is robust, without causing double-announcements that could happen if the button itself tried to read its state changes while maintaining focus.
