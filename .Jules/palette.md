## 2024-05-22 - Temporary Button Feedback & Screen Readers
**Learning:** When adding temporary visual feedback states to buttons (like swapping a Save icon to a Check icon for 2 seconds), dynamically updating the button's `title` or `aria-label` attribute often causes screen readers to double-announce the change (or announce inconsistently).
**Action:** Instead of mutating the button's accessible name, add a separate, visually hidden element with `aria-live="polite"` inside the component. Render the feedback text (e.g., "Chart saved") in this live region only when the temporary state is active. This ensures a clean, single announcement without disrupting the static button labeling. Additionally, always clear `setTimeout` calls within `onBeforeUnmount` to prevent buggy state updates or memory leaks.
